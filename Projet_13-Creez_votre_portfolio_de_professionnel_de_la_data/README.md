# Projet 13 – Créez votre portfolio de professionnel de la data

## 🧾 Mission

Pour ce projet, l’objectif principal était la création d’un portfolio professionnel en ligne regroupant l’ensemble des projets réalisés au cours de la formation Data Analyst.
Le contexte est basé sur une demande fictive du client Aéroworld, une entreprise souhaitant analyser rapidement les compétences techniques et la posture professionnelle de ses futurs consultants.

Le but : produire un portfolio clair, structuré, consultable en ligne, et intégrant tous les éléments d’évaluation nécessaires pour valider les compétences d’un Data Analyst.

## 🎯 Objectifs pédagogiques

- Créer un portfolio professionnel complet et consultable par un recruteur.
- Formaliser un cahier des charges fonctionnel répondant aux besoins du client.
- Concevoir un diagramme de Gantt pour planifier le projet.
- Réaliser une analyse des besoins métier d’Aéroworld.
- Produire une carte mentale synthétisant les priorités du projet.
- Rédiger une documentation claire sur la création de graphiques sous Power BI.
- Développer un mini-dashboard interactif pour démonstration dans une vidéo.
- Présenter une vidéo tutorielle (8–12 min) guidant la création d'un dashboard BI.
- Structurer le projet selon une approche professionnelle de consultant.

## 🧰 Outils utilisés
- **Power BI**	Dashboard + vidéo tutorielle
- **GitHub Pages**	Hébergement du portfolio en ligne
- **PowerPoint / Canva**	Carte mentale, structuration du projet, support visuel
- **Markdown + GitHub Repository**	Structuration et documentation
- **Power Query / DAX**	Manipulation de données et mesures
-  **Share X** Editeur d'enregistrement d'écran, enregistrement de la vidéo de formation

## 🧠 Compétences acquises

Gestion complète d’un projet Data Analyst du cadrage à la livraison.
Structuration d’un portfolio professionnel orienté employabilité.
Rédaction et formalisation d’un cahier des charges fonctionnel.
Création et documentation d’un dashboard pédagogique et réutilisable.
Capacité à se positionner comme consultant avec une réponse client argumentée.
Conduite d’une démonstration filmée et vulgarisation des concepts BI.
Rédaction de documentation technique claire et reproductible.

## 💬 Soft skills

Prise d’initiative et autonomie dans la construction du projet.
Capacité d’organisation, planification et priorisation (Gantt).
Transmission pédagogique et vulgarisation dans la vidéo tutorielle.
Communication structurée et orientation utilisateur.
Créativité visuelle pour la mise en forme du portfolio.
